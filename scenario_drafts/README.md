# Scenario drafts

Co-authors don't use the repository. They send their drafts to Soham, who saves each one here as received, one file
per scenario, named after the scenario (e.g. `homecare_suspension.md`). Drafts follow the template in
`SCENARIO_GUIDE.md` (section 8). Each includes the design card, versions B and C, the answers from the three LLM
checks, and the LLM tools and models used. Drafts are reviewed together before being converted into
`phase1/scenarios/`.
